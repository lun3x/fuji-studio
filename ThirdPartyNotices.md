Adaptation: the documented property addresses identify a bounded read-only descriptor probe; no write examples, saved-bank modifications, or model-specific look mappings are adopted. Upstream X-T5 4.20 support is a research claim, not evidence from this user's hardware.

Phase-B adaptation additionally uses the documented direct-value read sequence and candidate signed/unsigned field encodings, with camlib's 1/2/4-byte mode-value convention retained only as a labeled candidate interpretation. No descriptor type, X-T5 look mapping, or upstream sample value is presented as an observation from the user's camera.

Phase-C import adapts only the documented D18C selection/read sequence and conservative 100 ms settling interval. Saved-bank writes from the upstream examples are excluded. Film/grain table membership is used only to flag unresolved values while all rendering remains disabled; grain 7 is retained verbatim for future physical conversion validation.
